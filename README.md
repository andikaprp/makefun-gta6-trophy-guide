Leonida Legend - an offline GTA VI trophy guide and tracker for all 55 PS5 trophies. A master-detail board groups the checklist by roadmap step with the selected trophy's full guide open beside it; every guide names its sources on screen, the six trophies with no confirmed method carry honest readings instead of invented steps, and Positive Mental Attitude gets the missable watch it deserves. Progress is saved locally, hidden trophies sit behind a spoiler shield, and the eight-step roadmap runs from touchdown to the platinum.

## Run it

```sh
node main.ts          # validates the data and builds the dossier into /output
node serve.ts         # or serve the guide itself at http://localhost:8080
```
